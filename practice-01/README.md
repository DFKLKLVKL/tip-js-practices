    Тип document: object

Различие: в Node.js typeof document равно undefined, потому что Node.js — серверная среда выполнения и не предоставляет DOM. В браузере document — это объект, точка входа в DOM-дерево HTML-страницы, поэтому typeof document равно object.

Примечание: браузер выводит предупреждение Unsafe attempt to load URL file://.... Это особенность безопасности Chromium для локальных файлов, на работу ПР1 не влияет.

## Задание 2. Исследование типов и преобразований

| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
|---|---|---|---|---|
| "8" + 2 | "82", string | "82" | string | Оператор + со строкой выполняет конкатенацию: число 2 превращается в "2" и приклеивается. |
| "8" - 2 | "8", string | 6 | number | Оператор - не работает со строками, "8" автоматически преобразуется в число. |
| Number("8") + 2 | 10, int | 10 | number | Явное преобразование в число, далее арифметика. В JS нет типа int. |
| "12" > "3" | true, boolean | false | boolean | Обе строки, сравнение лексикографическое: "1" < "3". |
| 12 === "12" | false, boolean | false | boolean | Строгое равенство не преобразует типы, number ≠ string. |
| Number("") | 0, int | 0 | number | Пустая строка преобразуется в 0. |
| Number("text") | 0, int | NaN | number | Нечисловая строка → NaN, при этом тип NaN — number. |
| Boolean("false") | true, boolean | true | boolean | Любая непустая строка истинна; "false" — просто текст. |
| typeof null | null, ? | "object" | string | Историческая особенность JS: typeof null → "object". Результат typeof — строка. |
| typeof NaN | null, int | "number" | string | NaN имеет тип number. Результат typeof — строка. |

## Задание 5. Поиск логических ошибок через DevTools

Исходный вывод программы (с ошибками):

    Выполнено: 32
    Осталось: -24
    Контрольная сумма: 6

Таблица ошибок

| Ошибка | Что наблюдалось | Причина | Исправление | Результат после исправления |
|---|---|---|---|---|
| Обработка количества задач | Выполнено: 32, Осталось: -24 | Строки "3" и "2" конкатенируются через +, затем строка вычитается | Number(completedText) + Number(additionalText) | Выполнено: 5, Осталось: 3 |
| Граница цикла | Контрольная сумма: 6 вместо 10 | Условие < 4 не включает 4, суммируются только 1, 2, 3 | Заменил на <= 4 | Контрольная сумма: 10 |

Исправленный вывод:

    Выполнено: 5
    Осталось: 3
    Контрольная сумма: 10
